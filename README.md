# Titanic Dataset - EDA (Exploratory Data Analysis)

## 📌 Objective:
Analyze Titanic dataset using visual and statistical methods to derive patterns, trends, and insights.

## 📊 Tools Used:
- Python (Pandas, Seaborn, Matplotlib)

## 📈 Key Visuals:
- Histograms
- Boxplots
- Heatmap
- Pairplot

## 📑 Summary:
- Survival rate was higher for females and 1st class passengers.
- Age and Fare played key roles in survival.
- Dataset cleaned and null values handled efficiently.
